# Build the Docker Image

```
sudo ./build-docker.sh
```

# Run agy

```
./agy-sandbox.sh
```

# Deployment (Optional)

Copy the script to a directory in your `PATH`:
```
cp agy-sandbox.sh ~/bin/agy
```

Or create an alias:
```
alias agy='/path/to/agy-sandbox.sh'
```

Once set up, you can run it using `agy`
